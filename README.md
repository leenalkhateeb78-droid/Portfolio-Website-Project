# Leen Alkhateeb — Portfolio Website

A personal portfolio website designed and developed to showcase my skills, projects, education, and experience as a Software Engineer and Frontend Developer.

## About the Project

This portfolio website presents my professional profile in a simple, clean, and responsive design. It includes information about my background, technical skills, projects, education, and ways to contact me.

## Features

* Responsive design for desktop, tablet, and mobile
* About Me section
* Skills section
* Projects showcase with interactive image previews
* Education and experience overview
* Downloadable CV
* Contact section with input validations and styling
* Clean and simple user interface using CSS variables
* Hover effects and smooth visual animations for enhanced UX

## Technologies Used

* HTML5 (Semantic Markup)
* CSS3 (Grid, Flexbox, Custom Properties, No `rem` units, Pure Pixel precision)
* Responsive Web Design
* Figma (for UI/UX wireframing and prototyping)

# Leen Alkhateeb — Portfolio Website

A personal portfolio website designed and developed to showcase my skills, projects, education, and experience as a Software Engineer and Frontend Developer.

## About the Project

This portfolio website presents my professional profile in a simple, clean, and responsive design. It includes information about my background, technical skills, projects, education, and ways to contact me.

## Features

* Responsive design for desktop, tablet, and mobile
* About Me section
* Skills section
* Projects showcase
* Education and experience
* Downloadable CV
* Contact section
* Clean and simple user interface
* Hover effects and smooth visual interactions

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Figma

To run the project locally:

```bash

```

Open the project folder and launch `index.html` in your browser.
